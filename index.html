Why word timing matters for voice agents

  • Barge-in detection: when the agent is speaking and the user starts mid-sentence, word-level onset times tell the agent where the user cut in and what to do with the tail of its own utterance (keep, rewind, or drop).
  • Subtitle alignment: word timestamps are exactly what caption/overlay systems need to light up each word as it is spoken — no forced alignment post-pass required.
  • Latency measurement: comparing the last word's end time against response onset measures end-of-turn → answer latency, the number voice-agent teams obsess over.
